# Audio files

Put bundled mp3 files here.

Examples:

- `normal_001.mp3`
- `normal_002.mp3`
- `warning_001.mp3`
- `pressed_001.mp3`
- `pressed_002.mp3`

The app reads mp3 files from the bundle and chooses matching prefixes at runtime.

You can generate the files with:

```powershell
python tools/generate_tts.py
```
